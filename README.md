# 🎬 Alura+ - Landing Page Promocional

[![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)](https://developer.mozilla.org/pt-BR/docs/Web/HTML)
[![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)](https://developer.mozilla.org/pt-BR/docs/Web/CSS)

Landing page inspirada nas principais plataformas de streaming do mercado, desenvolvida para promover a assinatura do serviço Alura+ e do plano Combo+. O projeto foca no uso de CSS Grid Layout, variáveis CSS e pseudo-classes para estados interativos.

---

## 📌 Destaques da Implementação

- 📐 **CSS Grid Layout:** Alinhamento de conteúdo em colunas e seções responsivas com `grid-template-columns`.
- 🎨 **Variáveis CSS (`:root`):** Centralização e padronização da paleta de cores e tipografia (`--cor-de-fundo`, `--botao-azul`, `--fonte-principal`), facilitando a manutenção da identidade visual.
- 🖱️ **Estados Interativos:** Aplicação de pseudo-classes `:hover` e `:active` nos botões de chamada para ação (CTA) e nos links do rodapé para aprimorar a experiência do usuário.
- 📱 **Semântica HTML5:** Utilização de tags semânticas (`<section>`, `<ul>`, `<footer>`) organizadas para destacar recursos, dispositivos compatíveis e termos de assinatura.
